How credentials are stored

Every value above is an environment variable, not a row in the database and not a line in the code. On this machine they live in a .env file that is excluded from version control; on the hosted copy they are Vercel environment variables marked secret, which the dashboard will not display back even to the person who set them.

Secrets are shown here only as a character count. A screen that prints an API key is a screen that leaks it to whoever is standing behind you.

None of these providers may carry patient data until a BAA is signed with them. That is a contract, not a setting, and no green light on this page stands in for it.
