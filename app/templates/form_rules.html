⚡ Rules

Rules show or hide a question depending on an earlier answer — only asking about pregnancy, for instance, if an earlier question was answered yes.

Not built yet. The data model has a place for conditional logic, but the editor and the evaluator are not written. Every question on a page is currently shown to every patient.

This one matters for correctness rather than convenience: a hidden question must never be trusted from the browser, so the rule has to be re-evaluated on the server at submit time. That is the part worth doing carefully.
